# Template Authoring — Foundation Contract

Templates are versioned production assets, not runtime AI code.

Phase 0 defines only the registry contract. The first Salon & Spa template is built in Phase 3.

Every real template will require:

- ID
- niche
- archetype
- immutable version
- supported/required fields
- section list
- fallback behavior
- DNA options
- asset slots
- fixture configs
- desktop/mobile visual approval
